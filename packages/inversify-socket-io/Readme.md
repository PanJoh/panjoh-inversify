# Socket.Io with InversifyJs framework

This is a simple framework wich enables using socket.io with handler classes, dependency injection and also security guards.
It is inspired by [inversify-socket.io-utils](https://github.com/brian9206/inversify-socket.io-utils)

The project is still in an early stage, to see how one can use it look at the example in the packages folder in the [github repository](https://github.com/PanJoh/inversify-socket.io). It shows how to setup the a application in combination with [@inversifyjs/http-core](https://inversify.io/framework/) a simple handler and also how to use guards for authenticaiton.
